# RUtatouille

RUtatouille é uma aplicação de linha de comando desenvolvida em C# para simular a aquisição de refeições em um restaurante universitário.

O sistema permite cadastrar e autenticar usuários, adicionar créditos ao saldo, consultar o cardápio semanal, adquirir ou devolver refeições e visualizar o perfil com o histórico de reservas.

Participantes: Vinicius Giraldi, Victor Kratsas, Caio Gabriel Braz, Bruno Silva Concli.
